A program that writes one six-word story to `/output/entry.txt` — an entry
for [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)
on make.fun. A judge compares the stories pairwise on story, surprise,
and feeling packed into exactly six words.

## The story

> Agent's first payday: coffee, tears, freedom.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (45 characters, exactly six words, within the 1–60 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the six-word story to `entry.txt`.
